## 方法与它的两次修正

**第一轮:纵向逐行读**(约 27,000 行)
按文件读,搞清楚"每个文件做什么"。产出:调用可达性、参数流、缺陷清单。

**第一次修正:加运行记录对账**
只读代码会把"进程存在"误当成"它在工作"。
典型教训:曾判定"video-loop 常驻一直录",而 682 段视频的时间戳证明它**只在巡检窗口内录**。

**第二次修正:改纵向为横向,按通道扫**
这个系统的进程之间**没有函数调用**,全靠六类通道通信。
"谁调用谁"这个框架抓不住它的真实结构 —— 已发现的缺陷 **100% 在进程边界上,0% 是函数调用错误**。
六类通道:**文件 · 环境变量 · ROS 参数 · ROS 话题 · 日志字符串 · 退出码**,已全量对账。
